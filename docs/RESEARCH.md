# Research dossier

Reviewed: 2026-10-28

Targeted primary-source review, not an exhaustive systematic review. Abstract-level evidence unless a section locator is recorded. No experiments reproduced. Translations are original summaries; source material remains under its own license.

23 primary sources covering research, evaluations, software weaknesses and official practice/platform documentation. This collection does not measure overall failure prevalence. Chainwright efficacy is unmeasured.

## R01 · Asleep at the Keyboard? Assessing the Security of GitHub Copilot's Code Contributions

[Asleep at the Keyboard? Assessing the Security of GitHub Copilot's Code Contributions](https://arxiv.org/abs/2108.09293v3) · 2021 · `research`

89 security-oriented scenarios produced 1,689 programs; approximately 40% were vulnerable in this experiment.

Limit: Early Copilot and selected high-risk scenarios; not a current universal vulnerability rate.

Inspected: Abstract; IEEE S&P 2022 accepted paper

Protocol mapping (our design judgment): `code_review`

## R02 · Do Users Write More Insecure Code with AI Assistants?

[Do Users Write More Insecure Code with AI Assistants?](https://arxiv.org/abs/2211.03622v3) · 2023 · `research`

Participants with the codex-davinci-002 assistant produced less secure code and were more confident in its security.

Limit: A particular user study and model; confidence is not a substitute for verification.

Inspected: Abstract; ACM CCS 2023

Protocol mapping (our design judgment): `premise_audit`

## R04 · We Have a Package for You! A Comprehensive Analysis of Package Hallucinations by Code Generating LLMs

[We Have a Package for You! A Comprehensive Analysis of Package Hallucinations by Code Generating LLMs](https://arxiv.org/abs/2406.10279v3) · 2025 · `research`

16 models generated 576,000 Python/JavaScript samples. Reported average hallucinated-package percentages were at least 5.2% for commercial and 21.7% for open-source models.

## Interpretation

A prompt adapter is not an enforced runtime, and valid JSON does not prove correctness. Historical model metrics are not current model comparisons. General review guidance motivates checks but does not establish a measured Chainwright improvement rate.
