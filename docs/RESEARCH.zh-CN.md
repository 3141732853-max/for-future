# 研究资料汇编

核实日期：2026-10-28

定向收集一手资料，不是穷尽性的系统综述；除注明具体章节外，仅核实摘要层面的结论。未复现实验。中文为原创摘要，不转载论文正文。

共 23 项一手来源，覆盖研究、评估、软件弱点与官方实践/平台文档。不提供失误的整体发生率；Chainwright 的实际效果尚未测量。

## R01 · Asleep at the Keyboard? Assessing the Security of GitHub Copilot's Code Contributions

[Asleep at the Keyboard? Assessing the Security of GitHub Copilot's Code Contributions](https://arxiv.org/abs/2108.09293v3) · 2021 · `research`

该实验在 89 个安全相关场景生成 1,689 个程序，约 40% 存在漏洞。

边界：早期 Copilot 与特定高风险场景，不能推广为当前全部 AI 代码的漏洞率。

核实位置：Abstract; IEEE S&P 2022 accepted paper

协议映射（本项目的设计判断）：`code_review`

## R04 · We Have a Package for You! A Comprehensive Analysis of Package Hallucinations by Code Generating LLMs

[We Have a Package for You! A Comprehensive Analysis of Package Hallucinations by Code Generating LLMs](https://arxiv.org/abs/2406.10279v3) · 2025 · `research`

16 个模型生成 576,000 个 Python/JavaScript 样本；论文报告商业模型与开源模型的平均虚构包比例至少为 5.2% 和 21.7%。

边界：这是实验设置下的包比例，不是开发者比例、全部样本错误率或当前模型错误率；包存在也不等于可信。

核实位置：Abstract; USENIX Security 2025 paper

协议映射（本项目的设计判断）：`premise_audit`
